# 日中用語対照表

本ディレクトリ（`go_game_ja`）は中国語原版 `go_game` の日本語訳である。翻訳にあたり、**中国語の漢字をそのまま日本語語彙として使い回す「造語」を避け**、禁手なしの本アプリに合う「五目並べ」の一般的な日本語表記に統一した。なお、黒に禁手を課す競技ルールである「連珠」の用語は、同義語の確認・参考のために引用する。

用語の拠り所：公益社団法人日本連珠社「連珠とは」、Wikipedia「五目並べ」「連珠」、連珠ルールブック（用語とその定義）、および一般的なソフトウェア日本語表記。
